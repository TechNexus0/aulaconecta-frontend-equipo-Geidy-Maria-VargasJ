# aulaconecta-frontend-equipo-Geidy-Maria-JuanV
Organiza, optimiza y administra tu espacio de trabajo con tus colaboradores

AulaConecta presenta dificultades para organizar y centralizar la información del proyecto, lo que genera problemas de comunicación y seguimiento entre los colaboradores.
Crear un front-end que centralice la información del proyecto y facilite la colaboración entre los integrantes del equipo.

Nuestro alcance inicial en esta primera etapa se preparará la estructura del proyecto y la documentación inicial. En futuras fases se desarrollarán las páginas de inicio de sesión, panel principal, gestión de actividades, consulta de entregas y visualización de observaciones del instructor.

Criterios de calidad para fusionar una contribución

Antes de realizar un merge, cada contribución debe cumplir con los siguientes criterios:

1. Los cambios deben estar relacionados únicamente con la tarea asignada.
2. El código o la documentación deben estar revisados y sin errores de ortografía o formato.
3. El commit debe tener un mensaje claro y descriptivo que explique el cambio realizado.
4. Los archivos deben mantener una estructura organizada y nombres claros.
5. No debe incluir información sensible, archivos innecesarios ni afectar el funcionamiento de la rama principal (main).
